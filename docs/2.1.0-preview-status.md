# 2.1.0 development checkpoint

This is incomplete development work, not a release candidate. Do not tag or publish 2.1.0 from this checkpoint. Existing v2.0.0 release assets and tags are unchanged.

## Executed locally

- `npm ci` / dependency installation succeeds (pinned frontend dependencies).
- `npm run build --prefix frontend`: TypeScript check and Vite production build pass.
- `npm test --prefix frontend`: 9 bridge validation/browser-isolation tests pass.
- `git diff --check` passes.

## Implemented; Windows verification pending

- In-place WPF/WebView2 host with packaged virtual-host assets; no production localhost dependency.
- React Home, horizontal game selection, Library search/sort/favorites, game editor and launch profiles.
- Performance view with backend measurements, request/process timestamp distinction, recommendations and local history.
- Settings UI connected to persistence and host startup/tray preferences.
- Closed bridge dispatch and correlation, sender-origin check, navigation restriction and frontend CSP.
- Bridge transaction serialization; edits preserve stored LastPlayed/LaunchCount; successful launches persist them.
- Process CPU/working-set sampler; system CPU uses GetSystemTimes deltas rather than summed live-process lifetimes.
- Added backend malformed-envelope and missing-payload tests (not executed locally).
